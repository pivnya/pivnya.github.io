[HUGO](https://gohugo.io/) is a brilliant framework for static websites, which allows you to build your own websites quickly and offers flexibility and ease of use. And do I hate the themes for it. Especially [PaperMod](https://github.com/adityatelange/hugo-PaperMod), as I've used it myself.  
  
PaperMod theme sucks. Easy to set up, but so fucking difficult to modify. Tons of CSS files that need to be overridden manually one by one. A lot of useless features, with very unreadable code. It provides a very streamlined experience, and sites using it look the same! I can see from a mile if a HUGO site is using this theme. On top of that, it's bloated.  
  
You need to jump through every hoop just to personalise it for yourself. It is indeed very easy to set up and just start working. Will you learn anything about HUGO and how it works? No. You will learn to work with PaperMod and the features it provides.  
  
I changed my theme to [LUGO](https://github.com/LukeSmithxyz/lugo), by the meme guy, **Luke Smith**. It's very simple and offers barebones options, and I finally could breathe with ease.
